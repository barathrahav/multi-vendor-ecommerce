# Project Context

Project: Multi Vendor E-Commerce

Stack:
- React + TypeScript
- Apollo Client
- Node + Express + GraphQL
- Prisma + PostgreSQL

Architecture:
- Modular GraphQL schema/resolvers
- Service layer business logic
- Prisma ORM only
- JWT authentication
- Role-based authorization

Coding Standards:
- Strict TypeScript
- Reusable utility functions
- No business logic in resolvers
- Keep services modular
